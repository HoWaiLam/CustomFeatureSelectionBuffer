DESCRIPTION

Photogrammetric models deliver realistic visuals for 3D web maps but rely on other supplementary data layers for feature selection and information retrieval.

An existing 2D building polygon layer can serve this purpose, but discrepancies between the perceived feature boundary in the photogrammetric model and the actual feature boundary in the supplementary data layer adversely affect the accuracy of these operations.

Here is an example of a photogrammetric model of several city blocks and the 2D building polygon layer used for building selection and retrieving basic building information. The exclusion of covered balconies and bay windows from the building polygon layer creates discrepancies between the polygons and the perceived building boundaries in the photogrammetric model. As a result, users may be unable to retrieve information when clicking or hovering over what appears to be part of a building.

To reduce these discrepancies, a feature selection buffer can be computed for each building polygon. This is a non-uniform buffer that expands into unoccupied space while preserving shared boundaries with neighbouring buildings.
